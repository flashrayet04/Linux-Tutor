Commands by Linux Distro

Core Bash commands are the same everywhere — but package management and some system tools differ by distro family. Pick your family below to see exactly what to type.

Why do commands differ?

Every Linux distro ships with a package manager — the tool you use to install, update, and remove software. Each distro family chose a different one:

Debian/Ubuntu apt
Fedora/RHEL dnf
Arch pacman
openSUSE zypper

Everything else — files, navigation, processes, permissions — is universal.
